# sethseokheehan.github.io

Source of Seth Seokhee Han's academic homepage at https://sethseokheehan.github.io, built with Jekyll (jekyll, jekyll-scholar, jekyll-sitemap) with publications from `_bibliography/papers.bib`.

## Preview locally

Run `docker compose up` and open http://localhost:8080. Docker is required; the image is ruby:3.3.5, the same Ruby as CI.
